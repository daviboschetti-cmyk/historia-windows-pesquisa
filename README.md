| **Windows 2.0**| 1987 | Possibilidade de sobrepor janelas. | Gerou um processo judicial da Apple por copiar elementos do Macintosh. |
| **Windows 3.x** | 1990 | Gerenciador de Programas e suporte a 256 cores. | Foi a versão que popularizou o jogo *Paciência* para ensinar o uso do mouse. |
| **Windows 95** | 1995 | Menu Iniciar e Barra de Tarefas. | A Microsoft pagou milhões para usar a música "Start Me Up" dos Rolling Stones no comercial. |
| **Windows 98** | 1998 | Integração com a internet e suporte a hardware Plug and Play. | Primeira versão a incluir o navegador Internet Explorer como parte do sistema. |
| **Windows ME** | 2000 | Foco em multimídia e atualizações automáticas. | Introduziu a Restauração do Sistema para recuperar arquivos e configurações. |
| **Windows 2000** | 2000 | Sistema mais estável voltado para empresas e redes. | Baseado no Windows NT, trouxe melhor gerenciamento de usuários e segurança. |
| **Windows XP** | 2001 | Estabilidade (Kernel NT) e novo visual "Luna". | A famosa imagem do papel de parede (Bliss) é uma foto real, sem Photoshop. |
| **Windows Vista** | 2007 | Interface gráfica renovada com efeitos Aero. | Introduziu o Controle de Conta de Usuário (UAC) para maior segurança. |
| **Windows 7** | 2009 | Melhor desempenho e interface refinada com a barra de tarefas redesenhada. | Teve foco em estabilidade, compatibilidade e usabilidade, corrigindo falhas do Vista. |
| **Windows 8/8.1** | 2012 / 2013 | Interface voltada para telas sensíveis ao toque com a Tela Inicial de blocos (Metro). | Removido o menu Iniciar clássico, gerando polêmica entre os usuários. |
| Windows 10 | 2015 | Retorno do menu Iniciar com integração de blocos dinâmicos. | Introduziu atualizações contínuas e o assistente virtual Cortana. |
| **Windows 11** | 2021 | Menu Iniciar centralizado e suporte a apps Android. | É a primeira versão que exige obrigatoriamente o chip de segurança TPM 2.0. |


## 🛠️ Como Contribuir
1. Faça um Fork do projeto.
2. Crie uma branch para sua versão: `git checkout -b feature/versao-faltante`.
3. Commit suas mudanças: `git commit -m 'Adicionando Windows Vista'`.
4. Push para a branch: `git push origin feature/versao-faltante`.
